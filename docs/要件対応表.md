# 要件対応表

sheet-writer が満たす振る舞い（仕様）の一覧。

| # | 要件 | 仕様詳細 |
| --- | --- | --- |
| A1 | 列幅の機械計算（fit/wrap・縮めない） | |
| A2 | wrap列へのWRAP設定 | |
| A3 | 行高の機械設定（10+16×行数・最小26px） | |
| A4 | ヘッダー行38px担保 | |
| A5 | 上の行との書式揃え | |
| A6 | 書き込み後の読み戻し検証 | |
| A7 | checkerの違反検出（幅・折り返し・行高） | |
| A8 | --fixは書式のみ（値・数式に触らない） | |
| A9 | 実IDはリポジトリ外のローカル設定 | |
| A10 | 規約スキルの数値実体はtool側が正 | |
| B1 | userEnteredValue照合 | |
| B2 | タブ不一致の例外化 | |
| B4 | textFormat検証 | 検証で textFormat のサブキー（bold・italic・fontSize・fontFamily）も突き合わせる |
| B5 | 疎グリッド変換の検証 | |
| B6 | fixの報告件数 | |
| B7 | wrap列幅の違反化 | wrap 列も設定幅未満なら width 違反にし、fix で設定幅へ拡大（明示100px・未設定とも違反） |
| B8 | 数式継承は対象外 | 数式の継承・コピーダウンは本 tool の対象外 |
| B10 | 設定エラーの終了コード2 | load_config が不備を ValueError に包み、CLI は終了コード2で終わる |
| B11 | insertDataOption指定 | append の params に insertDataOption=INSERT_ROWS を指定する |
| D1 | セル内改行前提の行数計測 | |
| D3 | 配置・数値書式の上の行との一致 | |
| D5 | 列幅変更後のメタデータ読み戻し | |
| E1 | checker背景色チェック | background_rule 有効時のみ。白の明示設定も違反。--fix で除去 |
| E2 | writerは背景を持ち込まない | 継承から背景キーを除外し、残存は検証エラー |
| E3 | 末尾判定列 append_anchor_column | writer は update で anchor 最終行の直後へ書き、checker の検査範囲も同行まで |
| F1 | anchor 経路の書式リセット | anchor 経路では追加行の各セルへ全継承キーを fields に挙げた repeatCell を意図書式が空でも送り、書込先に残っていた書式をマスクで消す |
| F2 | anchor 検証と設定厳格化 | Target で append_anchor_column を `^[A-Z]+$` で検証し、load_config はターゲットの未知キーと background_rule の bool 以外を ValueError にする。writer は anchor 列に値のある行が無ければ書き込まず ValueError |
| F3 | writer 列幅計算の末尾範囲統一 | compute_column_widths のデータ行も、anchor 設定時は anchor 最終行までに限定し、checker の検査範囲に揃える |
| H1 | checkerチェックボックス設定チェック | checkbox_columns で列挙した列のみ（opt-in）。真偽値（boolValue 入力または表示値 TRUE/FALSE。文字列の "FALSE" も含む）があるのに BOOLEAN の入力規則がないセルを違反にし、--fix は setDataValidation で入力規則のみを設定する（値・書式に触らない）。anchor 設定時は検査範囲も anchor 最終行まで |
| H2 | gatewayのdataValidation取得 | get_state の取得フィールドに dataValidation を追加し、SheetState.data_validations（セル単位の dict グリッド）として保持する |
